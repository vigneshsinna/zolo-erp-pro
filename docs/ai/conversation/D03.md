# D03 — Voice continuation

Stacked on D02 (`1de2d1e`). Before the change, the focused confirmed-voice continuation test returned HTTP 500 because attached audio bypassed conversation routing.

Audio preparation now returns the existing extraction for transcript review when bound to an active task. It never calls the new-task handoff for that reply. Chat consumes the current, explicitly confirmed extraction revision; verifies actor, company, branch, FY, thread and task; and feeds the transcript through the same correction path as text. Receipt events retain media/extraction revision references and voice provenance. Existing transcription, confirmation, warnings, private media policy, gateway and credit metering are reused. Dictate already submits editable text and requires no new transcription implementation. TranscriptExtractionV1 already preserves uncertainty and self-correction warnings; no duplicate schema was added.

Validation: `php vendor/bin/phpunit -c scratch/conversation.phpunit.xml tests/Feature/Ai/Conversation/ActiveTaskRoutingTest.php tests/Feature/Ai/Multimodal --log-junit scratch/d03-final.xml` passed 40 tests / 309 assertions, no failures or skips, on PHP 8.5.12 / PHPUnit 12.5.43 and guarded disposable MySQL `zolo_test_conversation_20261117`.

The red test had 1 failure / 3 assertions; its fixed version passed 1 test / 9 assertions. Additional tests cover unconfirmed uncertainty, stale transcript revision, wrong branch, extraction reuse and preparation without a duplicate task. Voice inputs are persisted fixtures, not live recordings or provider evidence. D07 supplies transcript review and composer integration. No browser, staging or production verification is claimed.

Rollback: disable `AI_CONVERSATION_ENABLED` or revert this PR. Preserve media, extraction revisions, draft and audit records. No new migrations or financial writes.
